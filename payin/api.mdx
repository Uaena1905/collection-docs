### 订单创建

<div className="api-table-wrap">

| 请求连接 | 请求方式 | 授权 |
| --- | --- | --- |
| https://{"{测试/线上环境域名}"}/v2api/createpayorder.php | POST | 商户发起付款信息调用通知 UD 平台取得付款链接 |

</div>

### 请求参数

<div className="api-table-wrap">

| 参数名称 | 是否必传 | 类型 | 最大长度 | 描述 |
| --- | --- | --- | --- | --- |
| appId | 是 | String | 32 | UD后台的appId |
| game_code | 是 | String | 128 | 商户应用名称，商户提供 |
| merchantOrder | 是 | String | 32 | 商户订单号(确保唯一) |
| price | 是 | float | 10 | 美金金额0.99-499.9（元） |
| payCallbackUrl | 是 | String | 256 | 商户支付回调url |
| redirectUrl | 是 | String | 256 | 支付重定向跳转 |
| currencyCode | 是 | String | 12 | 支付的币种(USD) |
| payChannelDesc | 是 | String | 64 | 商品描述 |
| userId | 是 | String | 32 | 商户用户ID |
| time | 是 | int | 13 | 时间戳（秒） |
| sign | 是 | String | 128 | 算签名法和规则5.5 |
| payChannel | 是 | String | 32 | 支付方式代码 |

</div>

### 响应结果

```json
{
    "status": "1",
    "payUrl": "https://pay-gate.ugamedeal.com/pay.php?a=showPay&orderId=ZE5x3pDWE",
    "msg": "下单成功",
    "orderId": "88882023110913561097408"
}
```

### 结果说明

<div className="api-table-wrap">

| 字段说明 | 类型 | 最大长度 | 描述 |
| --- | --- | --- | --- |
| status | int | 11 | 1 表示授权成功，0失败 |
| orderId | String | 64 | UD订单号 |
| payUrl | String |  | 付款页面连接(跳转到付款页面支付) |

</div>
