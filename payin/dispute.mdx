### 拒付回调请求参数

<div className="api-table-wrap">

| 参数名称 | 是否必传 | 类型 | 最大长度 | 描述 |
| --- | --- | --- | --- | --- |
| type | 是 | number | 1 | 付款结果 (1=拒付创建，2=拒付抗辩 3=抗辩失败 4=抗辩成功) |
| merchantOrderId | 是 | String | 128 | 商户订单号 |
| ctime | 是 | int | 13 | 时间戳(秒) |
| payOrder | 是 | String | 64 | UD订单号 |
| sign | 是 | String |  | 签名规则：[查看配置与签名文档](/config) |
| msg | 否 | String | 200 | 拒付原因 |
| appId | 否 | String | 200 | UD后台的appId |

</div>

### 支付回调返回结果

商户收到UD的拒付回调需要返回json数据：

```json
{
    "status": "1",
    "msg": "success"
}
```

### 拒付回调返回结果代码说明

<div className="api-table-wrap">

| 参数 | 描述 |
| --- | --- |
| status | 1 表示商户已经收到回调 |
| msg | 商户的提示信息 |

</div>
