UgameDeal 代收（Payment Collection）- 全球收款解决方案

## 一、代收产品是什么（客户视角）

UgameDeal 代收（Payment Collection / 资金收款）：商户通过 UD API，为用户提供多种本地支付方式，用户通过信用卡、银行卡、电子钱包等方式向商户账户支付，资金直接进入商户 UD 账户，无需自行对接各国支付渠道。

- **资金方向**：用户银行卡 / 本地钱包 → 商户 UD 账户
- **支付场景**：游戏充值、商城购物、订阅服务、虚拟商品购买
- **覆盖区域**：全球 200+ 个国家和地区，支持 150+ 种本地支付方式
- **接入方式**：HTTPS + IP 白名单 + 参数签名（MD5 / RSA_SHA256）
- **模式**：支付下单 ＋ 支付页面跳转 ＋ 异步回调通知 ＋ 订单查询 ＋ 退单申请

## 四、如何使用代收功能

- **开通流程**：联系 UgameDeal 商务团队申请开通代收权限，提交商户资质
- **接入方式**：通过 API 接口对接，生成支付链接，用户跳转支付页面完成支付
- **安全保障**：采用 HTTPS 加密传输 + IP 白名单 + 参数签名验证 + PCI DSS 合规
- **到账时效**：支付成功后实时到账商户账户，结算周期根据合同约定（T+1、T+7 或月结）
- **费率说明**：按交易金额百分比收取手续费，不同支付方式费率不同，具体请咨询商务团队
- **回调通知**：支付成功后系统自动向商户服务器发送异步回调通知，确保订单状态同步
- **退款支持**：支持部分支付方式的退款功能，具体规则请参考退单接口文档
