UgameDeal Pay-in (Payment Collection) — a global collection solution

## 1. What is pay-in (merchant view)

UgameDeal Pay-in (Payment Collection): through the UD API, merchants offer users multiple local payment methods. Users pay via credit card, bank card, or e-wallet into the merchant account. Funds go directly into the merchant’s UD account without integrating each country’s payment channels yourself.

- **Fund flow**: User bank card / local wallet → merchant UD account
- **Payment scenarios**: Game top-up, store checkout, subscriptions, virtual goods
- **Coverage**: 200+ countries and regions, 150+ local payment methods
- **Integration**: HTTPS + IP allowlist + parameter signature (MD5 / RSA_SHA256)
- **Mode**: Create order ＋ payment page redirect ＋ async callback ＋ order query ＋ refund request

## 4. How to use pay-in

- **Onboarding**: Contact the UgameDeal business team to enable pay-in and submit merchant credentials
- **Integration**: Connect via API, generate a payment link, and redirect the user to complete payment
- **Security**: HTTPS encryption + IP allowlist + signature verification + PCI DSS compliance
- **Settlement timing**: Funds credit the merchant account in real time after success; settlement cycle follows the contract (T+1, T+7, or monthly)
- **Fees**: Percentage of transaction amount; rates vary by method — contact the business team for details
- **Callbacks**: After success, the system sends an async callback to your server to sync order status
- **Refunds**: Supported for some methods; see the refund API docs for rules
