### Callback request parameters

<div className="api-table-wrap">

| Parameter | Required | Type | Max length | Description |
| --- | --- | --- | --- | --- |
| isSuccess | Yes | number | 1 | Payment result (`1` = success, `2` = failure) |
| merchantOrderId | Yes | String | 128 | Merchant order ID |
| ctime | Yes | int | 13 | Timestamp (seconds) |
| payOrder | Yes | String | 64 | UD order ID |
| sign | Yes | String |  | Signature rules: [see Config and signature](/en/config) |
| currencyCode | Yes | String | 12 | Order currency |
| price | Yes | String | 10 | Order amount |
| msg | No | String | 200 | Failure reason |
| appId | No | String | 200 | appId from the UD console |
| payCode | No | String | 200 | Payment method code |

</div>

### Callback response

After receiving the UD payment callback, the merchant must return JSON:

```json
{
    "status": "1",
    "msg": "success"
}
```

### Callback response codes

<div className="api-table-wrap">

| Parameter | Description |
| --- | --- |
| status | `1` means the merchant received the callback and started fulfillment; any other value means fulfillment failed (defined by the merchant) |
| msg | Merchant message |

</div>

### Payment redirect

UD appends `merchantOrderId` (the merchant order ID) to the redirect URL provided by the merchant, then redirects the user back.
